# DeveWay API Endpoints

Generated by reading every `*.controller.ts` under `apps/api/src/modules` (31 controllers; 3 of the modules, `quizzes`, `tracks` and the admin sub-controller of tracks, define more than one controller class). All paths below are relative to the global prefix `/api` (for example `POST /api/auth/login`). Interactive docs are available at `/api/docs` outside production.

## How to read this document

Auth column values:

| Value | Meaning |
|---|---|
| Public | No guard on the route. There is NO global JWT guard in this app, so a route without `JwtAuthGuard` is open to anyone. |
| JWT | `JwtAuthGuard`: valid access token required. Ownership and finer role checks (student, consultant, instructor) are often done inside the service. |
| JWT + ADMIN | `JwtAuthGuard` + `RolesGuard` with `@Roles('ADMIN')`. `SUPER_ADMIN` always passes. |
| JWT + ADMIN/SUPER_ADMIN | Same, with both roles listed. |
| Optional JWT | `OptionalJwtGuard`: works without a token, richer result with one. |
| Special | A different guard (`RefreshGuard`, `StreamAuthGuard`, Stripe or provider signature). |

Response format: nearly every response goes through `TransformInterceptor`, which returns `{ "success": true, "data": <payload>, "meta": { timestamp, path, method, requestId, duration } }`. If the handler already returns an object with a `success` key it is passed through unchanged. Errors go through `HttpExceptionFilter`. The `data` payload shape is defined by each service; the Description column states the notable payload where the controller makes it explicit. Request bodies are validated by a global `ValidationPipe` (`whitelist` and `forbidNonWhitelisted`, so unknown properties are rejected with 400 on DTO-typed bodies).

Rate limiting: global `ThrottlerGuard` with buckets of 10 requests per second, 100 per minute and 500 per 15 minutes per client; some auth routes are tighter (noted below).

CSRF: `/api/auth`, `/api/wallet`, `/api/admin`, `/api/payments`, `/api/certificates` are behind `CsrfMiddleware` (token from `GET /api/csrf/token`, sent as `x-csrf-token`).
