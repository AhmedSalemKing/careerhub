# CareerHub Web

Main application for CareerHub.

## Ports
- Default: 3000

## Scripts
- `npm run dev`: Start development server on port 3000
- `npm run build`: Build for production
- `npm start`: Start production server on port 3000

## LMS Integration
The LMS (Learning Management System) is isolated on port 3002.
Links to `/learn` or `/courses` (for learning) point to `http://localhost:3002`.
